## 踩过的坑

### 坑 1：普通用户没有 sudo
- 现象：`rocky is not in the sudoers file. This incident will be reported.`
- 原因：RHEL 系默认只有 `wheel` 组成员能 `sudo`；`usermod` 也需要 root
- 解法：控制台以 root 执行 `usermod -aG wheel rocky`，**退出重登后**才生效
- 教训：Linux 权限靠「组 + 重新登录」，不是装完就有

### 坑 2：ICMP 不通但 SSH 通
- 现象：宿主机 `ping 10.0.0.150` 失败，但 22 端口可连
- 原因：桥接环境下 ICMP 常被防火墙丢弃
- 结论：判断服务是否可达，**以 TCP 端口为准**，别用 ping 下结论

### 坑 3：桥接 IP 会变
- 现象：DHCP 续租后 IP 变化，SSH 连不上
- 解法：路由器做 MAC 绑定，或改用 NAT + 端口转发

## 今天踩的 5 个坑（全部实测）

### 坑 4：`su: 未找到命令`
- 现象：SSH 里执行 `su -` 报 command not found
- 原因：Rocky 8.10 **最小化安装**未包含 `su`
- 解法：VMware 控制台以 root 登录修 wheel；之后用 `sudo dnf install` 补工具
- 教训：最小化安装 ≠ 完整系统，运维第一课是"确认工具在不在"

### 坑 5：`grep: /etc/droup: No such file or directory`
- 原因：路径拼错（`group` 打成 `droup`）
- 解法：Tab 补全；`ls /etc | grep -i group` 先确认文件存在
- 教训：报"文件不存在"先怀疑自己拼错

### 坑 6：`grep wheel/etc/group` 卡住不动
- 原因：少了空格，`grep` 只收到一个参数 → 把 `wheel/etc/group` 当成"要找的内容"，等待 stdin
- 解法：`Ctrl + C` 取消，补上空格
- 教训：命令"挂起"先 `Ctrl+C`，再判断是不是在等输入

### 坑 7：加了 wheel 但 `id` 里没有、sudo 仍报不在 sudoers
- 原因：**shell 会话的组信息在登录时固化**，改 `/etc/group` 不影响已登录会话
- 解法：断开重连 FinalShell（或 `newgrp wheel` 临时生效）
- 教训：改用户/组 → 必须重登录；改服务配置 → 必须重启服务

### 坑 8：sudo 密码连错三次
- 原因：`sudo` 要 **rocky 自己的密码**，不是 root 密码
- 分清三条路：
  | 场景 | 密码 | 能力 |
  |---|---|---|
  | `sudo` | 自己的密码 | 授权范围内的命令 |
  | `su -` | root 密码 | 变成 root（本机缺 su） |
  | polkit 弹窗（如 hostnamectl） | root 密码 | 仅当次操作 |
- 教训：别再往 `sudo` 里填 root 密码
