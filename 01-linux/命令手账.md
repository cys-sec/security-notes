## day1 实操：文件与目录（2026-11-12）

> 场景：在 `~/linux-practice` 下把 6 个基础命令各用一遍。
> 结局：src/ 留 note.txt，dst/ 留 note.txt，共 2 个文件；临时文件已删。

```bash
$ pwd
/home/rocky

$ mkdir -p ~/linux-practice/src ~/linux-practice/dst
$ cd ~/linux-practice && pwd
/home/rocky/linux-practice

$ ls -lah
drwxrwxr-x. 2 rocky rocky   6 Nov 12 09:08 dst
drwxrwxr-x. 2 rocky rocky   6 Nov 12 09:08 src

$ echo "hello linux" > src/note.txt
$ echo "second file" > src/note2.txt
$ ls -lah src
-rw-rw-r--. 1 rocky rocky 12 Nov 12 09:08 note2.txt
-rw-rw-r--. 1 rocky rocky 12 Nov 12 09:08 note.txt

$ cp src/note.txt dst/            # 复制单个文件
$ mv src/note2.txt dst/renamed.txt   # 移动 + 改名
$ ls -lah dst
-rw-rw-r--. 1 rocky rocky 12 Nov 12 09:08 note.txt
-rw-rw-r--. 1 rocky rocky 12 Nov 12 09:08 renamed.txt

$ ls -lah dst/renamed.txt    # 【删前先确认】
$ rm -f dst/renamed.txt
$ ls -lah dst
-rw-rw-r--. 1 rocky rocky 12 Nov 12 09:08 note.txt
```

**要点**
- `ls -lah`：`-a` 连隐藏文件（`.` 和 `..`）、`-l` 长格式、`-h` 人性化单位
- `cp` 复制文件；复制目录要 `cp -r`
- `mv` = 移动 **或** 改名（这里是 `note2.txt → renamed.txt`）
- `rm` 不可恢复：**删之前先 `ls` 看一眼**；`rm -rf` 尤其危险

## day2 复习记录（2026-11-13）

> 完整复盘见 `03-notes/Linux-Day2-复盘-2026-11-13.md`。当天没有学新命令，而是把 #1–6 在真实场景里用了一遍。

- `cp -r /etc ~/text0`：普通用户只能拷到 87 项，大量 Permission denied，可用 `sudo diff -rq /etc ~/text0/etc` 对比出缺哪些（audit/、firewalld/、grub.d/ 等）
- `su root` 不带 `-`：CWD 不变但 HOME 变 /root，`~/text0` 被解析到 /root 下 → 用 `su -` 或直接写绝对路径
- `cp -r` 目标不存在：内容会铺进目标（得到 /root/text0/passwd），而不是 /root/text0/etc
- `du -sh 目录 -type f` 是错的：看大小用 `du -sh`，数文件用 `find 目录 -type f | wc -l`

## day3 实操：查找与查看（2026-11-14）

> 环境：`rocky@cys`，素材用 Day2 的完整副本 `~/text0/etc-full`（429 个文件）。

```bash
$ which bash
/usr/bin/bash
$ which sshd
/usr/sbin/sshd
$ echo $PATH
/home/rocky/.local/bin:/home/rocky/bin:/usr/local/bin:/usr/bin:/usr/local/sbin:/usr/sbin

$ find ~/text0/etc-full -name "*.conf" -type f | wc -l
87
$ find ~/text0/etc-full -name "*.conf" -type f | head -3
/home/rocky/text0/etc-full/gcrypt/random.conf
/home/rocky/text0/etc-full/dbus-1/session.conf
/home/rocky/text0/etc-full/dbus-1/system.conf

$ find /etc -maxdepth 1 -type f -name "*conf*" | head -5
/etc/resolv.conf
/etc/sudo.conf
/etc/libuser.conf
/etc/xattr.conf
/etc/libaudit.conf

$ file /bin/ls
/bin/ls: ELF 64-bit LSB shared object, x86-64, dynamically linked, ... stripped
$ file ~/text0/etc-full/services
/home/rocky/text0/etc-full/services: UTF-8 Unicode text
$ file ~/text0/etc-full/mtab
broken symbolic link to ../proc/self/mounts
$ file ~/text0/etc-full/passwd
ASCII text

$ cat /etc/hostname
cys
$ wc -l /etc/hostname
1 /etc/hostname

$ wc -l ~/text0/etc-full/services
11473 ~/text0/etc-full/services
$ head -n 5 ~/text0/etc-full/services
# /etc/services:
# $Id: services,v 1.49 2017/08/18 12:43:23 ovasik Exp $
#
# Network services, Internet style
# IANA services version: last updated 2016-07-08

$ less -F /etc/hostname
cys
```

**要点**

- `find 路径 -name "*.conf" -type f`：**通配符必须加引号**，否则 shell 先展开，find 收不到模式
- `which` 只查 PATH；找不到时用 `command -v` 或绝对路径（如 `/usr/sbin/sshd`）
- `file` 看「文件本质」不看扩展名；**软链会直接告诉你目标在不在**（`broken symbolic link to ../proc/self/mounts` —— 正好印证 Day2 diff 里那 6 条相对软链失效）
- `cat` 只适合短文件；`services` 有 **11473 行**，用 `head` 或 `less`
- `less` 是交互式的：`q` 退出、空格/`b` 翻页、`/关键词` 搜索、`G` 到末尾、`gg` 到开头
- 非交互环境（脚本、`ssh host "命令"`）里 `sudo` 会报「需要终端」→ 用 `sudo -S` 从标准输入读密码，或 `ssh -t` 分配终端
