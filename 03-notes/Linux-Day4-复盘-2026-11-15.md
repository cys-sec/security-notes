## 二、三个新知识点（比命令更值钱）

### 1. 副本 = 快照，会过期

`etc-full` 是 11/13 22:52 的快照。11/14 装了 open-vm-tools / fuse / fontconfig 之后，`/etc` 多了 21 个 `.conf`，副本自然对不上。**这不是复制失败，是时间差。**

以后每次练习前先看一眼：

```bash
sudo diff -rq /etc ~/text0/etc-full 2>/dev/null    # 空 = 一致；有输出 = 漂移
```

### 2. 文件 mtime ≠ 安装时间

`stat` 显示 `fonts.conf` 是 2021-10-12、`fuse.conf` 是 2024-02-07，看着像"老文件"，但实际是 11/14 才装的——因为 **rpm 安装时保留包内原始时间戳**。
判断"什么时候装的"只能靠 `rpm -q --last 包名`。做入侵排查时同理：**不能只看文件时间**。

### 3. `sudo` 不能随便塞进进程替换

`comm -23 <(sudo find …) <(…)` 里，sudo 在子进程里拿不到终端读密码 → `Input/output error`。两种解法：

```bash
sudo -v      # 先缓存凭证（5 分钟有效），再跑 <( … ) 就没问题
# 或者：sudo 只出现在行首，分步执行、结果落 /tmp 文件
```

## 四、#7–12 今天做了什么

| 命令 | 今天的用法 | 要点 |
|------|-----------|------|
| find | `find etc-full -name "*.conf"`；`-size +20k`；`sudo find /etc` | 条件可叠加；全盘加 `2>/dev/null` |
| which | `which sshd`、`which -a python3`、`type ls` | `type` 能识别别名/内建 |
| file | `mtab`（断链）、`/bin`（软链）、`/bin/ls`（ELF）、`passwd`（ASCII）、SSH 私钥 | 先 file 再决定用什么看 |
| cat | `cat /etc/os-release`、`cat -n services` | 长文件别裸 cat，配 head/less |
| less | 本想看 `messages`，文件不存在 → 改用 `journalctl` | **先 ls 确认文件存在** |
| head/tail | `head -n 5`、`tail -n 5 services` | `tail -f` 尚待补做（用 `journalctl -f -u sshd`） |
